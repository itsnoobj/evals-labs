How it is built

One file, two graders, one scripted agent

flowchart TD C["5 refund cases<br/>order, total, eligible"] --> A P["Prompt v1 or v2<br/>one-line diff"] --> A A["Scripted agent<br/>picks the next tool call"] --> T["3 tools<br/>lookup_order, check_eligibility, issue_refund"] T --> R["Run record<br/>tool trace, reply, refund ledger"] R --> G1["Grader A: answer-only<br/>stand-in for final_response_match"] R --> G2["Grader B: trajectory<br/>exact tool names and args, plus ledger rule"] G1 --> O["Terminal report<br/>green or red per case"] G2 --> O

Scripted agent

No LLM call. v1 follows the policy. v2 deviates on A3, A4, A5 exactly as in the deck. Deterministic, so the demo cannot flake on stage.

Grader A: answer-only

Passes when the reply says the refund was processed. Replies omit the amount, like a real support bot, so this grader cannot see money errors.

Grader B: trajectory

Score = matched expected calls / max(expected, actual). Pass needs exact tool order and args. Also fails if total refunded exceeds the order total.
